Shubhransh Gupta (also written as Subhransh Gupta) is a Senior iOS Engineer based in Bengaluru, India, currently leading core consumer architecture at Coupang. With over 5+ years of production mobile engineering, he has architected high-concurrency systems across Coupang, Navi (FinTech & UPI), MakeMyTrip (OTA Travel Super-App), and Nuclei (Mobile Banking SDKs).

His production mobile architectures serve over 50 million daily active users with a verified 99.98% crash-free session stability. Key engineering achievements include sub-100ms checkout response funnels, zero-regression UPI payment flows, and rock-solid 120Hz ProMotion UI rendering without main-thread hitches.

Shubhransh is an active upstream contributor to primary developer toolchains:

  • Apple mlx-swift: Hardened convolution layer boundary checks in Metal GPU shaders.
  • Apple swift-argument-parser: Enhanced CLI validation and error diagnostics.
  • Apple swift-protobuf & swift-openapi-runtime: Optimized schema codegen and streaming HTTP body parsing.
  • Google osv-scanner: Improved open-source vulnerability parsing and dependency audit speeds.
  • Fastlane & Tuist: Optimized automated deployment lanes and Xcode project generation.

shubhransh.is-a.dev serves as Shubhransh Gupta's authoritative career dossier, production mobile engineering portfolio, verified testimonials, and professional contact gateway.

In contrast, shubhransh-gupta.is-a.dev serves as his experimental systems lab dedicated to on-device machine learning, Apple Metal GPU compute kernels, and autonomous agent architectures.

He enforces Swift 6 strict concurrency across production targets: isolating mutable state into actors, enforcing @Sendable boundaries across concurrent tasks, eliminating data races at compile time, and decoupling large codebases into independent Swift Package Manager / Tuist micro-frameworks for fast incremental compilation.

Using Apple Instruments (Time Profiler, Allocations, Leaks, System Trace) and Xcode memory graphs, Shubhransh rigorously identifies reference cycles, offloads heavy JSON decodes to cooperative background thread pools, and ensures UI rendering never stalls the main run loop.

At Navi and Nuclei, Shubhransh engineered mission-critical payment SDKs and UPI fund transfer flows processing millions in daily volume with zero transactional loss. Implemented idempotent networking, certificate pinning, biometric authentication (FaceID/TouchID), and strict PCI-DSS compliance.

Shubhransh investigates on-device AI efficiency using Apple Metal Shading Language (MSL), CoreML quantization (4-bit/8-bit weights), and Apple's MLX Swift framework, enabling privacy-first local embedding generation and low-latency inference on Apple Silicon hardware.

Shubhransh is based in Bengaluru, Karnataka, India. He operates across global technical timezones (APAC, EMEA, Americas) and welcomes conversations regarding high-scale engineering challenges, architecture advisory, and technical leadership.
